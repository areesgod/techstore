## 1. ОБЩАЯ ХАРАКТЕРИСТИКА ПРОЕКТА

### 1.1 Наименование и назначение системы

**Наименование:** Информационная система электронной торговли «TechStore».

**Назначение:** Веб-приложение для автоматизации процессов розничной онлайн-торговли цифровыми и физическими товарами технической направленности. Система обеспечивает полный цикл торговых операций: от регистрации пользователя до выполнения заказа, включая программу лояльности и управление сетью филиалов.

### 1.2 Основные характеристики

| Параметр | Значение |
|----------|----------|
| Тип системы | Веб-приложение (SPA + REST API) |
| Целевой рынок | Республика Казахстан |
| Языки интерфейса | Русский (по умолчанию), Казахский, Английский |
| Валюта | Казахстанский тенге (₸) |
| Количество товаров | 30 (15 цифровых + 15 физических) |
| Количество филиалов | 5 (Алматы, Астана, Шымкент, Қарағанды, Ақтөбе) |
| Покрытие доставки | 55 городов Казахстана |
| Уровней лояльности | 9 |
| Способов оплаты | 3 (карта, наличные, рассрочка 3/6/12 мес.) |
| Производственный URL | https://techstore-nine-iota.vercel.app |
| API URL | https://techstore-x45t.onrender.com/api |

### 1.3 Роли пользователей системы

| Роль | Описание | Доступ |
|------|----------|--------|
| Гость | Незарегистрированный посетитель | Каталог, поиск, регистрация |
| Покупатель | Верифицированный пользователь | Заказы, кешбэк, личный кабинет |
| Сотрудник | Работник конкретного филиала | Портал `/employee` |
| Администратор | Суперпользователь | Панель `/admin` |

## 3. ОПИСАНИЕ АРХИТЕКТУРЫ СИСТЕМЫ

### 3.1 Общая архитектура

Система построена по трёхзвенной архитектуре клиент–сервер–база данных, реализованной как разделённое (decoupled) приложение:

```
Пользователь
     │
     ▼
[Vercel CDN]
React SPA
(techstore-nine-iota.vercel.app)
     │
     │ HTTPS REST API
     ▼
[Render Web Service]
FastAPI Application
(techstore-x45t.onrender.com)
     │
     │ TCP/5432
     ▼
[Render PostgreSQL]
База данных
     │
     ▼
[Resend API]
Email-уведомления
```

### 3.2 Технологический стек

**Клиентская часть:**
- **React 18** — UI-библиотека на основе компонентов и Virtual DOM
- **Vite 5** — сборщик с Hot Module Replacement
- **TailwindCSS 3** — utility-first CSS-фреймворк
- **React Router v6** — клиентская маршрутизация
- **i18next** — интернационализация (RU/KZ/EN)
- **Axios** — HTTP-клиент с перехватчиками

**Серверная часть:**
- **Python 3.11** — язык программирования
- **FastAPI 0.110+** — асинхронный веб-фреймворк
- **SQLAlchemy 2.x** — ORM для работы с PostgreSQL
- **Pydantic v2** — валидация и сериализация данных
- **bcrypt** — хэширование паролей
- **python-jose** — JWT-аутентификация
- **python-dotenv** — управление переменными окружения

**База данных и инфраструктура:**
- **PostgreSQL 15** — реляционная СУБД
- **Vercel** — хостинг фронтенда с глобальным CDN
- **Render** — хостинг бэкенда + managed PostgreSQL
- **Resend API** — транзакционные email-рассылки
- **GitHub** — репозиторий и CI/CD (автодеплой при push)

## 5. ОПИСАНИЕ ПРОГРАММНЫХ МОДУЛЕЙ

### 5.1 Модуль аутентификации (`routers/auth.py`)

**Эндпоинты:**

`POST /api/auth/register` — регистрация нового пользователя
- Принимает: `{name, email, password}`
- Проверяет уникальность email
- Хэширует пароль через bcrypt (12 раундов)
- Создаёт запись в `users` с `email_verified=False`
- Генерирует UUID-токен, сохраняет в `email_verification_tokens` (TTL 24 ч)
- Отправляет письмо верификации через Resend API
- Возвращает: `201 Created`

`POST /api/auth/token` — вход в систему
- Принимает: `{username (email), password}` (OAuth2PasswordRequestForm)
- Верифицирует пароль через `bcrypt.checkpw()`
- Генерирует JWT: `{sub: email, exp: now+30days}`, подпись HS256
- Возвращает: `{access_token, token_type: "bearer"}`

`GET /api/auth/me` — профиль текущего пользователя
- Требует: `Authorization: Bearer <token>`
- Декодирует JWT, возвращает объект пользователя
- Включает: уровень лояльности, баланс кешбэка

### 5.2 Модуль каталога (`routers/products.py`)

**Эндпоинты:**

`GET /api/products` — список товаров с фильтрами
- Query-параметры: `q` (поиск), `category`, `min_price`, `max_price`
- Нечёткий поиск: разбиение `q` на токены → `ILIKE %token%` по полям `name` и `description`
- Возвращает массив объектов Product

`GET /api/products/{id}` — детали товара
- Возвращает: данные товара + остатки по всем филиалам + срок доставки

### 5.3 Модуль заказов (`routers/orders.py`)

**Эндпоинты:**

`POST /api/orders` — создание заказа
```
1. Авторизация текущего пользователя (JWT)
2. Определение филиала по delivery_city (DELIVERY_MAP)
3. Расчёт суммы заказа (без учёта кешбэка)
4. Списание используемого кешбэка с баланса пользователя
5. Если payment_method == "card":
   а. Определение уровня лояльности по total_spent
   б. cashback_earned = total * tier_rate
   в. cashback_balance += cashback_earned
   г. total_spent += total (итог до вычета кешбэка)
6. Создание записи Order в БД
7. Создание записей OrderItem для каждой позиции корзины
8. Создание записи CashbackTransaction (earned и/или used)
9. Обновление BranchStock (уменьшение остатков)
10. Возврат созданного заказа
```

`GET /api/orders` — история заказов текущего пользователя

### 5.8 Email-уведомления (`email_utils.py`)

Все письма отправляются через **Resend HTTP API**:

```python
import requests

def send_email(to: str, subject: str, html: str):
    response = requests.post(
        "https://api.resend.com/emails",
        headers={"Authorization": f"Bearer {RESEND_API_KEY}"},
        json={
            "from": EMAIL_FROM,
            "to": [to],
            "subject": subject,
            "html": html
        }
    )
    return response.status_code == 200
```

Типы писем:
- **Верификация email** — ссылка вида `{FRONTEND_URL}/verify-email?token=<uuid>`, TTL 24 ч
- **Сброс пароля** — ссылка вида `{FRONTEND_URL}/reset-password?token=<uuid>`, TTL 1 ч

- Hero-баннер с призывом к действию
- Секция популярных категорий
- Блок с преимуществами магазина

**Каталог товаров (`/products`)**
- Боковая панель фильтров (категория, диапазон цен)
- Поиск в Navbar с debounce 300 мс
- Карточки товаров с изображением, ценой и кнопкой «В корзину»

**Страница товара (`/products/:id`)**
- Изображение, название, цена в ₸
- Список характеристик (features)
- Наличие в каждом из 5 филиалов
- Срок доставки для выбранного города
- Кнопка «Добавить в корзину»

**Корзина (`/cart`)**
- Список позиций с возможностью изменения количества
- Итоговая сумма
- Поле использования кешбэка (если есть баланс)
- Кнопка «Оформить заказ»

**Оформление заказа (`/checkout`)**
- Выбор города доставки (55 городов)
- Расчётный срок доставки
- Выбор способа оплаты:
  - Банковская карта (с начислением кешбэка)
  - Наличные при получении
  - Рассрочка (выбор: 3 / 6 / 12 месяцев + расчёт платежа)
- Данные для счёта (имя, email)
- Итоговая сумма с учётом использованного кешбэка

**Личный кабинет (история заказов, `/orders`)**
- Список заказов с датой, суммой и статусом
- Начисленный и использованный кешбэк

**Административная панель (`/admin`)**
- Вкладка «Дашборд»: выручка, число заказов, пользователей
- Вкладка «Товары»: таблица с редактированием и удалением
- Вкладка «Заказы»: полный список с фильтром по статусу
- Вкладка «Пользователи»: список с кнопками «Сделать администратором» и «Удалить»

**Портал сотрудника (`/employee`)**
- Заказы только своего филиала
- Кнопки смены статуса

### 6.3 Многоязычный интерфейс

Переключатель языка расположен в Navbar. При выборе языка:
1. Обновляется `localStorage.lang`
2. Вызывается `i18n.changeLanguage(lang)`
3. Все компоненты, использующие `useTranslation()`, ре-рендерятся с новыми текстами
4. Перезагрузка страницы не требуется

Примеры ключей перевода:

### 7.2 Команды запуска

**Бэкенд локально:**
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

**Фронтенд локально:**
```bash
cd frontend
npm install
npm run dev  # запуск на localhost:5173
```

**Docker Compose (оба сервиса):**
```bash
docker-compose up --build
```

### 7.3 CI/CD Pipeline

```
Разработчик
     │
     │ git push origin main
     ▼
GitHub Repository
     │
     ├──→ Vercel (автодеплой фронтенда)
     │     Build: npm run build
     │     Publish: dist/
     │
     └──→ Render (автодеплой бэкенда)
           Build: pip install -r requirements.txt
           Start: uvicorn main:app --host 0.0.0.0 --port $PORT
```

Время деплоя: фронтенд ~45 сек, бэкенд ~2–3 мин.

### 7.4 Инициализация данных (Seeding)

При первом запуске бэкенда автоматически выполняется:
1. **Создание таблиц** через `Base.metadata.create_all()`
2. **Заполнение 5 филиалов** (Алматы, Астана, Шымкент, Қарағанды, Ақтөбе)
3. **Загрузка 30 товаров** (15 цифровых + 15 гаджетов)
4. **Распределение складских остатков** по всем пяти филиалам

Создание администратора (отдельный скрипт):
```bash
cd backend
python seed_admin.py
```
